# Release Notes

Short release checklist for the quarterly release-manager drill.

## Pre-release checklist

- [ ] Verify all failing tests are triaged and blocking bugs are assigned before sign-off
- [ ] Confirm the version number and changelog entries are up to date in `RELEASE_NOTES.md`
- [ ] Run the full regression suite and attach the results to the release tracking issue
- [ ] Get at least one reviewer approval on the release PR before merging
- [ ] Tag the release commit and notify the release channel once `main` is updated
